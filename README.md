# 2D Distance Calculator

## Description
A Python command-line application that calculates the Euclidean distance between two points in a 2D coordinate system. The program utilizes Python's built-in function for optimal performance and includes robust input validation to prevent crashes from invalid, non-numeric user inputs.

## How to Run the Program
1. Ensure you have **Python 3.8 or higher** installed.
2. Save the code to a file named `main.py`.
3. Open your terminal or command prompt, navigate to the file's directory, and run:
   ```bash
   python main.py
   ```

## Input Needed
The program requires four numerical coordinate values entered sequentially through the command line prompt:
* **x1**: The X-coordinate of the first point.
* **y1**: The Y-coordinate of the first point.
* **x2**: The X-coordinate of the second point.
* **y2**: The Y-coordinate of the second point.

## Sample Output
```text
--- 2D Distance Calculator ---
Enter x1: 3
Enter y1: 4
Enter x2: 6
Enter y2: 8

The distance between (3.0, 4.0) and (6.0, 8.0) is 5.00
```
